## Is this still the limiting factor?

- If it doubled tomorrow, would the company's main rate go up? Y / N
- If N: stop this review and start one on the new limit: ______________

## Rules

1. Each person speaks for themselves. Their manager listens.
2. Bring the work, not a presentation about the work.
3. One number per person, written down every week.
4. Decide on the trend of four weeks, not on one bad week.
